# 🚀 AAYAM 2025 Hackathon Website

Welcome to the official website for the AAYAM 2025 Hackathon and related events!

## 📝 Overview
This website provides information, schedules, rules, and registration for the AAYAM 2025 Hackathon, including other technical events such as Fast Coding, Poster Making, Tech Quiz, and UI/UX Design. It is designed for students, participants, and organizers to easily access all event details.

- **Event Timeline:** View the schedule for both days, including inauguration, keynote, hackathon kickoff, presentations, and prize distribution.
- **Challenge Categories:** Explore different events and their rules, including Hackathon, Fast Coding, Poster Making, Tech Quiz, and UI/UX Design.
- **Hackathon Rules:** Detailed rules and eligibility for hackathon participants.
- **Dynamic Topics:** Add and manage hackathon topics interactively.
- **Registration:** Direct link to apply for events via Google Forms.
- **Modern UI:** Responsive and visually appealing design using HTML, CSS, and Font Awesome icons.

## 📁 File Structure
- `index.html` — Main landing page with event overview and schedule.
- `hackathon.html` — Hackathon details, rules, and dynamic topic management.
- `events.html` — List and details of all events.
- `fast-coding.html`, `poster-making.html`, `tech-quiz.html`, `ui-ux-design.html` — Individual event pages.
- `styles.css` — Custom styles for the website.
- `script.js` — JavaScript for interactive features (e.g., adding/removing topics).

## 🛠️ How to Use
1. Open `index.html` in your browser to view the main event page.
2. Navigate to specific event pages for more details.
3. Use the Hackathon page to view rules and add topics interactively.
4. Register for events using the provided Google Form link.
